# Portafolio Profesional - Lucas Troncoso

Landing Page profesional diseñada para captar reclutadores, líderes técnicos y potenciales clientes de consultoría.

## 🎯 Objetivo

Presentar de manera efectiva la experiencia senior en PHP/Laravel, liderazgo técnico y soluciones de cumplimiento normativo (Compliance).

## ✨ Características

- **Diseño Moderno Dark Mode**: Paleta de colores oscura con acentos en azul eléctrico y verde neón
- **100% Responsive**: Optimizado para dispositivos móviles, tablets y desktop
- **Animaciones Fluidas**: Efectos de scroll, transiciones y animaciones al entrar en viewport
- **Accesibilidad**: Navegación por teclado y mejoras de accesibilidad
- **Performance Optimizado**: Debounce en scroll handlers y lazy loading de animaciones

## 🚀 Tecnologías Utilizadas

- **HTML5**: Estructura semántica y accesible
- **CSS3**:
  - Variables CSS personalizadas
  - Flexbox y Grid Layout
  - Animaciones y transiciones
  - Media queries para responsive design
- **JavaScript Vanilla**:
  - Intersection Observer API
  - Smooth scroll
  - Mobile menu toggle
  - Animaciones dinámicas

## 📁 Estructura del Proyecto

```
portofolio/
```

## 🎨 Secciones de la Landing Page

1. **Hero Section**: Presentación principal con CTA destacado
2. **Skills**: Habilidades técnicas y de liderazgo
3. **About Me**: Perfil profesional y valores
4. **Projects**: Proyecto destacado con métricas de impacto
5. **Experience**: Timeline de experiencia profesional
6. **Contact**: CTA final y métodos de contacto

## 🌈 Paleta de Colores

- **Backgrounds**: `#0a0a0f`, `#111118`, `#1a1a24`
- **Accent Primary**: `#00d9ff` (Cyan eléctrico)
- **Accent Secondary**: `#0099ff` (Azul)
- **Accent Tertiary**: `#00ff99` (Verde neón)
- **Text**: Escala de grises desde `#ffffff` a `#8888a0`

## 📱 Responsive Breakpoints

- **Desktop**: > 1024px
- **Tablet**: 768px - 1024px
- **Mobile**: < 768px
- **Small Mobile**: < 480px

## 🔧 Instalación y Uso

1. Clona el repositorio:
```bash
git clone <repository-url>
cd portofolio
```

2. Abre `index.html` en tu navegador favorito

No requiere instalación de dependencias ni build process.
